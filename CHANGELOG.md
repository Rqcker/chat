# Changelog

Versions follow [semantic versioning](https://semver.org).

## Unreleased

- Continuous integration runs the unit tests on CPU.
- Evaluation scripts print the score only.
- Documentation and licence wording updated.

## v1.0.0 — 2026-09-11

First public release: the six-stage pipeline from one text prompt to a paired dyadic audio-visual clip, the two IFBR refinement weights (RFBG and SFBG) under `checkpoints/LICENSE`, the training and evaluation scripts documented in `DOCS.md`, and 119 unit tests that need neither a GPU nor a network.
