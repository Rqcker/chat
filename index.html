01 / Generated dialogues

Two faces, one conversation

Every clip below is generated end to end from a text prompt. Nothing is driven by a recorded video or a supplied script. Both sides are produced as a responsive pair, so the listening face reacts to the speaker inside the same clip.

speaker i speaker j

The interactive audio refinement block places every sentence and back-channel on a shared timeline, so speaking and listening alternate the way they do in a real exchange.

A listener is not a frozen frame. The silent-segment block keeps the non-speaking face alive across long stretches, and the continuity refinement removes the seams between segments.

One prompt yields many distinct conversations, with different content and different facial identities, which is what makes the pipeline usable as a data source.

Identities need not be photorealistic. The same pipeline drives illustrated and stylised faces without changing the method.

Clips are muted loops. Full narrated video and the complete set appear in the paper and supplementary material.

02 / Abstract
  • Audio-visual behaviour synthesis
  • Behavioural response generation
  • Diffusion model
  • Reaction generation

Large-scale dyadic interactive audio-visual dialogue (DIAD) datasets provide fundamental data resources for developing humanoid interactive virtual agents and digital humans. However, collecting such data is time-consuming, expensive, and ethically sensitive. To address this, we propose CHAT, a new dyadic interactive audio-visual dialogue generation (DIADG) framework that generates diverse, paired, and mutually responsive speech-face dialogue clips from a single textual prompt. CHAT unifies large language models and talking face models with interactive audio and facial behaviour refinement modules, enabling the generation of aligned dyadic dialogue clips with diverse contents and facial identities. Experiments show that CHAT outperforms existing related methods designed for similar tasks under both objective and subjective evaluations. Moreover, our synthesised CHAT-AVD-50k dataset serves as effective pre-training data for downstream interactive head generation, consistently improving PerFRDiff and ReactDiff on REACT 2024. CHAT offers a scalable alternative to the costly and ethically sensitive collection of real dyadic interaction data.

03 / Framework

Three modules, one pipeline

A prompt becomes a dialogue, the dialogue becomes interactive speech, and the speech drives a pair of face videos that answer one another.

  1. TDG

    Textual Dialogue Generation

    A language model turns one scenario prompt into several multi-turn dyadic scripts, each paired with two textual identity descriptors. Turns are generated segment by segment, conditioned on what was said before.

  2. DADG

    Dyadic Audio Dialogue Generation

    The interactive audio refinement block adds back-channels (uh-huh, hmm, okay, yeah), per-turn emotion, timestamps and a shared sound environment, then synthesises the two emotion-aware speech tracks on one timeline.

  3. IFBG

    Interactive Facial Behaviour Generation

    A talking-face model renders the speaking segments; the refinement block then generates the silent listening segments, makes each face responsive to its partner's behaviour, and blends the segment boundaries so the result reads as one continuous exchange.

07 / Honest limits
Inference cost
Each clip runs a language model, a speech model and several video diffusion passes, so synthesis at dataset scale is slow. Here scalable means demographic coverage, not a low per-clip cost.
Evaluation
The reaction metrics score the appropriateness and diversity of facial behaviour, not turn-taking timing or dialogue-level semantics. A metric for dialogue-level interaction quality remains open.
Scope
CHAT currently generates English dialogues, and the downstream study uses REACT 2024, on which the refinement block is pre-trained.
